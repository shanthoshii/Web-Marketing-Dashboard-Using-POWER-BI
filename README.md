# 📊 Web Marketing Dashboard - Power BI Project

This repository contains a Power BI dashboard that analyzes a real-world **web marketing dataset**. It provides valuable insights into user acquisition channels, campaign effectiveness, and conversion performance — supporting smarter marketing strategies.

---

## 📌 Project Overview

The **Web Marketing Dashboard** visualizes campaign and traffic source data to:
- Track visitor behavior and engagement
- Compare performance across devices and regions
- Measure campaign return on investment (ROI)
- Monitor bounce and conversion rates

---

## 📂 Dataset

**Filename**: `Web Marketing_Migrated Data.csv`

The dataset includes the following fields:
- `Campaign`: Name of the marketing campaign
- `Source`: Origin of the traffic (e.g., Google, Facebook)
- `Medium`: Channel type (e.g., Organic, CPC, Referral)
- `Sessions`, `Users`, `Pageviews`: Traffic metrics
- `Bounce Rate`: % of single-page sessions
- `Conversion Rate`: % of sessions that converted
- `Transactions`: Number of sales or conversions
- `Revenue`: Income generated from conversions
- `Country`: Visitor location
- `Device Category`: Desktop, Mobile, Tablet

> The data was cleaned and transformed using Power Query before visualization.

---

## 🧰 Tools and Libraries Used

- **Power BI Desktop**
- **Power Query** – for data transformation
- **DAX** – for calculated columns and KPIs
- **CSV File Input** – `Web Marketing_Migrated Data.csv`

---

## 🪜 Project Steps

1. Imported dataset into Power BI.
2. Cleaned and formatted data using Power Query.
3. Created relationships and calculated KPIs using DAX.
4. Built a multi-page dashboard with filters and interactivity.
5. Focused on clear, decision-oriented visual storytelling.

---

## 📊 Key Visualizations

- **Campaign vs Revenue** (Bar Chart)
- **Traffic Source and Medium** (Donut & Treemap)
- **Device Category Performance** (Clustered Bar)
- **Country-wise Transactions** (Map Visual)
- **Conversion Funnel** (Sessions → Conversions → Revenue)
- **Bounce Rate Analysis by Source** (Column Chart)

---

## 🔍 Insights and Findings

- Organic traffic drove the highest volume of sessions but had a moderate conversion rate.
- Paid campaigns like Google Ads contributed significantly to revenue.
- Mobile users made up the majority of traffic but had a slightly lower conversion rate.
- Bounce rate was highest for referral traffic from social media.
- The top 3 campaigns accounted for over 70% of total revenue.
